# Muhammad Bilal - Game Developer Portfolio

## 🎮 Professional Portfolio Website

A modern, responsive portfolio website showcasing Muhammad Bilal's game development work with 19+ published games.

### ✨ Features

- 🌓 **Light/Dark Theme** - Seamless theme switching with localStorage persistence
- 📱 **Fully Responsive** - Optimized for mobile, tablet, and desktop
- 🎨 **Modern Design** - Clean UI with smooth animations and transitions
- 🚀 **SEO Optimized** - Complete meta tags, Open Graph, and Schema.org markup
- ⚡ **High Performance** - Lazy loading, optimized assets, and efficient code
- 🎯 **Interactive** - Scroll animations, filter system, and dynamic navigation
- ♿ **Accessible** - Keyboard navigation and semantic HTML

### 📂 Project Structure

```
portfolio/
├── index.html          # Main HTML file with all sections
├── css/
│   └── style.css      # Complete styling with theme support
├── js/
│   └── script.js      # Interactive functionality
└── images/            # Game images and assets
```

### 🎯 Sections

1. **Hero** - Introduction with stats and social links
2. **About** - Professional summary and highlights
3. **Skills** - Categorized technical skills with progress bars
4. **Experience** - Timeline of work history
5. **Games** - Portfolio of 19+ published games with filter
6. **Education** - Academic background
7. **Contact** - Contact information and CTA

### 🎨 Design Features

- **Color Scheme**: Purple/Pink gradient theme
- **Typography**: Poppins + Orbitron fonts
- **Animations**: Fade-in, slide-up, hover effects
- **Icons**: Font Awesome 6.4.0
- **Layout**: CSS Grid + Flexbox

### 🚀 Quick Start

1. Open `index.html` in a modern web browser
2. No build process required - pure HTML/CSS/JS
3. Works offline after initial load
